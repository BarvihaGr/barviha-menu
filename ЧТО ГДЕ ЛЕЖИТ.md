# Что где лежит

Карта папки проекта «Барвиха Меню». Порядок наведён 05.10.2026.

## Корень

| Папка | Что внутри |
|---|---|
| `apps/menu` | Сайт меню для гостей (menu.barvikhagroup.ru) |
| `apps/hub` | Бэк-офис (menu.barvikhagroup.ru/back-off) |
| `packages/db` | Данные и логика меню, общие для сайта и бэк-офиса |
| `deploy` | Автодеплой на сервер и разовые правки контента |
| `scripts` | Служебные скрипты (диагностика сервера, старые переносы данных) |
| `_исходники (не для сайта)` | Таблицы, видео и тексты, из которых собиралось меню |
| `_архив` | Заметка: сам архив (старые версии, дубли, снятое с сайта — 149 МБ) с 09.10.2026 лежит на внешнем диске «Бамблби» в `BARVIKHA — РЕЗЕРВНАЯ КОПИЯ/Барвиха Меню — архив` |

Остальное в корне (`package.json`, `pnpm-*.yaml`, `tsconfig.base.json`, файлы с точкой) — настройки сборки, их не трогать.

## Фото, загруженные через бэк-офис

Лежат на сервере в `apps/menu/public/menu-admin`, в git не попадают. Раскладываются сами при загрузке:

`menu-admin/<локация>/<раздел>/<код позиции>-<время загрузки>.webp`

Например `menu-admin/paveletskaia/kitchen/kitchen-cold-app-syrnaia-tarelka-1784982157767.webp` — сырная тарелка, кухня Павелецкой. Фото категорий бара называются `category-<время>.webp`.

Рядом с каждым фото лежит превью `<имя>.webp.w720.webp` (720px, в 4–5 раз легче) — его показывают карточки списков, страница позиции показывает оригинал. Превью делает бэк-офис при загрузке; для старых фото — `deploy/thumbs/make-thumbs.mjs` (запускать из `apps/hub`). Если превью нет, nginx отдаёт оригинал.

Общие фото, которые Claude прикрепил сразу ко всем локациям (осеннее меню 2026 и т.п.), лежат в `menu-admin/_shared/<год-месяц>/` и названы по блюду: `vitello-tonnato-1.webp`.

## Данные меню

Названия, цены, описания, стоп-листы и аккаунты бэк-офиса лежат на сервере в `/var/www/barviha-data/content`, в git не попадают. На каждую локацию — папка с четырьмя файлами:

| Файл | Что внутри |
|---|---|
| `location.json` | Адрес, телефон, часы работы, включена ли локация |
| `kitchen.json` | Кухня |
| `bar.json` | Бар |
| `hookah.json` | Кальяны |

Рядом лежит `accounts.json` — аккаунты бэк-офиса. Копия всего этого и фото снимается каждую ночь в `/root/backups/menu`.

## Google Таблица меню — главный источник цен и позиций

С 14.10.2026 меню всех российских локаций (кроме тестовых ссылок) живёт в Google Таблице владельца «Правки по диджитал меню» (ссылка — у Петра; id таблицы записан в `deploy/sheet-sync/config.json`). Сервер сам сверяется с ней каждые 10 минут (`deploy/sheet-sync/sync.mjs`, крон `/etc/cron.d/barviha-sheet-sync`, лог `/var/log/barviha-sheet-sync.log`, отчёты в `content/.sheet-sync/`).

Что берётся из таблицы: названия, цены, состав меню (какие позиции есть), подраздел кухни/кальянов, раздел бара. Описание, состав, КБЖУ и объём из таблицы попадают только в пустые поля — тексты из бэк-офиса не затираются. Фото, стоп-лист, переводы и порядок остаются в бэк-офисе.

Правила таблицы: один лист — одна группа локаций (какая группа к каким точкам — в `config.json`, при перестановке точек между группами править там); строка с одним названием — заголовок раздела; колонки «Название | Категория | Цена | Описание»; цена бара «600 / 1300» — две цены за два объёма; строка без названия — не позиция. Позиция, которой в таблице больше нет, уходит в архив бэк-офиса (не удаляется). Листы «Ташкент (старый)» и «Ереван (старый)» не синхронизируются.
